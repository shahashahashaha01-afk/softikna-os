SOFTIKNA OS — PORTABLE EXE BUILDER

Это исходный проект + автоматическая сборка EXE через GitHub Actions. Сам готовый EXE в этом ZIP ещё не скомпилирован.

Самый простой способ:
1. Создай аккаунт/войдите в GitHub.
2. Создай новый репозиторий, например softikna-os.
3. Загрузи содержимое этого ZIP в репозиторий так, чтобы package.json, main.js, preload.js, index.html и папка .github находились в корне.
4. Открой вкладку Actions. Если GitHub спросит, разреши запуск workflow.
5. Запусти "Build Softikna OS Portable EXE" кнопкой Run workflow (либо сборка стартует после push в main).
6. После зелёной галочки открой запуск workflow → Artifacts → Softikna-OS-Portable-Windows и скачай архив с EXE.
7. Распакуй скачанный artifact и запускай Softikna OS.exe.

Приложение бесплатное; GitHub Actions имеет лимиты бесплатного использования. Для первой сборки нужен интернет.
В приложении работает оболочка, окна, настройки с сохранением, блокировка (PIN по умолчанию 1234), калькулятор, блокнот, экспорт заметки в Documents/Softikna OS, список файлов этой папки, ссылки открываются во внешнем браузере.
Softikna AI пока демонстрационный — для настоящих ответов нужно отдельно подключить реальный endpoint существующего Cloudflare Worker.
PIN-экран — простой локальный экран блокировки, не защита файлов уровня Windows.
